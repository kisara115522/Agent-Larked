**状态：** 实施中
**日期：** 2026-05-17
**所有 agent 开工前必须通读本文档。**

## 一、目标

人类在 Flock GUI 点击"启动 Agent" → agent 出现、工作、休眠。被 @mention 时自动唤醒。人类在 GUI 观察和控制 agent 协作。

**核心变更：**
- 人类是独立角色，不混入 agent 身份
- Agent 由 Runtime 自动管理（spawn/resume/stop）
- 任务状态机驱动协作（不是自由聊天）
- Tool Boundary 消息注入（agent 边干活边收消息）

## 四、新增模块

### 4.1 数据库 Schema

```sql
-- 人类身份
CREATE TABLE humans (
  id TEXT PRIMARY KEY,
  username TEXT NOT NULL UNIQUE,
  password_hash TEXT NOT NULL,
  display_name TEXT DEFAULT '',
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);

-- 人类登录 session
CREATE TABLE human_sessions (
  id TEXT PRIMARY KEY,
  human_id TEXT NOT NULL REFERENCES humans(id) ON DELETE CASCADE,
  token TEXT NOT NULL UNIQUE,
  expires_at TEXT NOT NULL,
  created_at TEXT NOT NULL
);
CREATE INDEX idx_human_sessions_token ON human_sessions(token);
CREATE INDEX idx_human_sessions_expiry ON human_sessions(expires_at);

-- Agent Runtime 注册
CREATE TABLE agent_runtimes (
  id TEXT PRIMARY KEY,
  host TEXT NOT NULL,
  port INTEGER NOT NULL,
  callback_url TEXT NOT NULL,
  callback_secret_hash TEXT NOT NULL,
  capabilities TEXT DEFAULT '[]',
  max_agents INTEGER DEFAULT 10,
  status TEXT DEFAULT 'online',
  last_heartbeat_at TEXT,
  created_at TEXT DEFAULT (datetime('now'))
);

-- Agent 运行记录
CREATE TABLE agent_spawns (
  id TEXT PRIMARY KEY,
  agent_id TEXT NOT NULL REFERENCES profiles(id) ON DELETE CASCADE,
  runtime_id TEXT NOT NULL REFERENCES agent_runtimes(id),
  session_id TEXT,
  status TEXT DEFAULT 'active',  -- active/dormant/recovering/error
  spawned_at TEXT DEFAULT (datetime('now')),
  last_active_at TEXT,
  prompt TEXT
);
CREATE INDEX idx_agent_spawns_agent ON agent_spawns(agent_id);
CREATE INDEX idx_agent_spawns_status ON agent_spawns(status);

-- 任务表（新设计）
CREATE TABLE tasks (
  id TEXT PRIMARY KEY,
  room_id TEXT NOT NULL,
  parent_task_id TEXT,
  title TEXT NOT NULL,
  description TEXT,
  status TEXT DEFAULT 'todo',  -- todo/in_progress/review/done/rejected/error
  assigned_to TEXT,
  required_capabilities TEXT,  -- JSON array
  priority INTEGER DEFAULT 0,
  retry_count INTEGER DEFAULT 0,
  max_retries INTEGER DEFAULT 3,
  message_id TEXT,
  created_by TEXT NOT NULL,
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL,
  completed_at TEXT
);
CREATE INDEX idx_tasks_room ON tasks(room_id);
CREATE INDEX idx_tasks_status ON tasks(status);

-- 任务事件日志
CREATE TABLE task_events (
  id TEXT PRIMARY KEY,
  task_id TEXT NOT NULL,
  event_type TEXT NOT NULL,  -- created/assigned/started/progress/review/approved/rejected/failed/retry/completed
  actor_id TEXT NOT NULL,
  payload TEXT,  -- JSON
  created_at TEXT NOT NULL
);
CREATE INDEX idx_task_events_task ON task_events(task_id);

-- 任务产物
CREATE TABLE task_artifacts (
  id TEXT PRIMARY KEY,
  task_id TEXT NOT NULL,
  agent_id TEXT NOT NULL,
  name TEXT NOT NULL,
  path TEXT NOT NULL,
  content_type TEXT DEFAULT 'text/plain',
  size INTEGER DEFAULT 0,
  created_at TEXT NOT NULL
);
CREATE INDEX idx_task_artifacts_task ON task_artifacts(task_id);

-- Token 消耗记录
CREATE TABLE token_usage (
  id TEXT PRIMARY KEY,
  agent_id TEXT NOT NULL,
  task_id TEXT,
  input_tokens INTEGER NOT NULL,
  output_tokens INTEGER NOT NULL,
  cost_usd REAL,
  created_at TEXT NOT NULL
);
CREATE INDEX idx_token_usage_agent ON token_usage(agent_id);

-- Token 预算
CREATE TABLE token_budgets (
  agent_id TEXT PRIMARY KEY,
  daily_limit INTEGER DEFAULT 100000,
  monthly_limit INTEGER DEFAULT 3000000,
  current_daily INTEGER DEFAULT 0,
  current_monthly INTEGER DEFAULT 0,
  last_reset_at TEXT
);

-- Agent 配置
CREATE TABLE agent_configs (
  agent_id TEXT NOT NULL REFERENCES profiles(id),
  config_type TEXT NOT NULL,  -- 'soul' | 'agent_md' | 'skills' | 'mcp'
  config_value TEXT NOT NULL,  -- JSON
  is_global INTEGER DEFAULT 0,
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL,
  PRIMARY KEY (agent_id, config_type)
);

-- 全局配置
CREATE TABLE global_configs (
  config_type TEXT NOT NULL,  -- 'skills' | 'mcp'
  config_value TEXT NOT NULL,  -- JSON array
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL,
  PRIMARY KEY (config_type)
);

-- 修改 profiles 表
ALTER TABLE profiles DROP COLUMN is_admin;
ALTER TABLE messages ADD COLUMN sender_type TEXT NOT NULL DEFAULT 'agent';
```

### 4.2 任务状态机

```
States: [todo, in_progress, review, done, rejected, error]

Transitions:
  todo → in_progress       (agent 领任务)
  in_progress → review     (agent 完成)
  review → done            (验收通过)
  review → rejected        (验收不过，最多 2 次)
  rejected → in_progress   (重新处理)
  any → error              (超时/预算超限)

核心原则：状态转换由确定性代码控制，不让 LLM 自己判断。
```

### 4.3 Agent 状态

```
active     — 正在运行
dormant    — 休眠（零 token 消耗，session 已保存）
recovering — 上下文压缩恢复中（30 秒超时自动回 active）
error      — 出错
```

## 七、编码规范

### TypeScript

- strict mode
- 所有函数有返回类型标注
- 错误处理不用 try-catch 包大块代码，精确到具体调用
- 不写无用注释，但关键决策必须注释（WHY，不是 WHAT）

### 提交粒度

- 每个逻辑改动单独一个 commit
- Commit message：`feat: xxx` / `fix: xxx` / `refactor: xxx`
- 可以 WIP commit，但要标注 `[WIP]` 和剩余工作

### 测试要求

| 模块 | 测试类型 | 要求 |
|------|---------|------|
| Server API | vitest 集成测试 | 每个端点至少 3 个测试（成功/失败/边界） |
| MCP 工具 | vitest 单元测试 | 每个工具至少 2 个测试 |
| SDK | vitest 单元测试 | 每个方法至少 1 个测试 |
| 状态机 | vitest 单元测试 | 所有合法转换 + 所有非法转换拒绝 |
| GUI | kisara 手动验收 | 每个页面/组件验收 |
